# 需求與規劃：全面看盤軟體

狀態：**需求訪談中**（2026-11-18 開始）。問答結果逐條記錄在下方，確定後再實作。

## 使用者已表達的需求

- 取代 e-Leader：主觀、直觀、好用、操作簡單。
- 四大頁面：**總覽／個股證券／期權／帳務**。
- 電腦與手機都能看（手機透過唯讀轉接站 + Tailscale）。
- 期權頁已完成第一版（T 字報價、8 項關鍵指標、右側走勢與五檔）。

## 初步架構提案

```
src/
  core/          共用：backend（HTTP+SSE）、行情中心（訂閱計數、報價快取）、換月、格式化、設定儲存
  pages/
    overview/    總覽
    stocks/      個股證券
    options/     期權（由現在的 main.ts 搬入）
    account/     帳務
  ui/            共用元件：圖表、五檔、報價列、卡片、表格
  app.ts         頁籤路由（#/overview、#/stocks/2330、#/options、#/account）
```

- 單頁應用，網址 hash 切換頁面；切頁時退訂不用的行情，避免超過訂閱上限（約 200）。
- 行情中心（QuoteHub）統一管理訂閱與報價，各頁共用，避免重複訂閱。
- 換月邏輯（pitfalls #1）抽成共用，台指期、小台、個股期貨都適用。

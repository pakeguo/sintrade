# 需求與規劃：全面看盤軟體

狀態：**需求訪談中**（2026-11-18 開始）。問答結果逐條記錄在下方，確定後再實作。

## 使用者已表達的需求

- 取代 e-Leader：主觀、直觀、好用、操作簡單。
- 四大頁面：**總覽／個股證券／期權／帳務**。
- 電腦與手機都能看（手機透過唯讀轉接站 + Tailscale）。
- 期權頁已完成第一版（T 字報價、8 項關鍵指標、右側走勢與五檔）。

## 初步架構提案

```
src/
  core/          共用：backend（HTTP+SSE）、行情中心（訂閱計數、報價快取）、換月、格式化、設定儲存
  pages/
    overview/    總覽
    stocks/      個股證券
    options/     期權（由現在的 main.ts 搬入）
    account/     帳務
  ui/            共用元件：圖表、五檔、報價列、卡片、表格
  app.ts         頁籤路由（#/overview、#/stocks/2330、#/options、#/account）
```

- 單頁應用，網址 hash 切換頁面；切頁時退訂不用的行情，避免超過訂閱上限（約 200）。
- 行情中心（QuoteHub）統一管理訂閱與報價，各頁共用，避免重複訂閱。
- 換月邏輯（pitfalls #1）抽成共用，台指期、小台、個股期貨都適用。

## 訪談紀錄

### 第 1 輪（2026-11-18）

| 問題 | 回答 | 對實作的影響 |
| --- | --- | --- |
| 總覽頁第一眼要看什麼 | **大盤與期權摘要**、**我的帳戶摘要**（不要自選股報價牆、不要排行榜） | 總覽 = 指數／台指期／期權關鍵指標精簡卡 + 帳戶損益與權益摘要 |
| 個股操作風格 | **當沖短線與波段都要** | 個股頁兩種模式可切換：盤中（分時、五檔、逐筆明細、內外盤、大單）／K 線分析（日週月 K、均線、技術指標） |
| 帳務頁範圍 | **期權＋證券都要** | 使用者需在永豐 API 管理頁把**證券帳戶**加入目前的 API Key；帳務頁分證券、期權兩區 |
| 手機看帳務 | **手機也能完整看** | `phone-server.mjs` 白名單要開放 `/portfolio/*` 與 `/auth/accounts`（唯讀查詢），仍封鎖 `/order/*` |

### 第 2 輪（2026-11-18）

| 問題 | 回答 | 對實作的影響 |
| --- | --- | --- |
| 期權頁還要看哪些商品 | **權值股動態**（不選小台、個股期、個股選、類股期） | 用 `index_components` 成分股貢獻點數串流（見 shioaji-api.md），呈現方式待第 3 輪確認 |
| K 線技術指標 | **均線＋成交量**、**RSI＋布林通道**、**VWAP＋籌碼價位（分價量表）**（不要 MACD／KD） | 個股與期貨 K 線共用指標模組 |
| 警示通知 | **暫時不需要** | 架構預留，但本階段不做 |
| 版面 | **固定版面** | 每頁由 AI 設計最佳配置，依使用者回饋調整；不做拖拉自訂 |

### 第 3 輪（2026-11-18）

| 問題 | 回答 | 對實作的影響 |
| --- | --- | --- |
| 權值股呈現方式 | **固定權值股清單**、**產業類股貢獻**（不要即時排行、不要自算指數） | 固定清單：報價 + 貢獻點數（`index_components` 取 `value`）；類股：`group_metric` 投影 |
| 權值股區塊位置 | **總覽與期權頁都放** | 總覽放精簡版、期權頁放完整版；做成共用元件 |
| 個股頁怎麼找股票 | **自選清單＋庫存自動帶入** | 左側自選清單（可分組，存在瀏覽器）+ 搜尋；證券庫存自動置頂 |
| 損益更新方式 | **即時跳動** | 用即時行情計算未實現損益；權益數等欄位定時（約 30 秒）向永豐查詢校正 |

### 第 4 輪（2026-11-18）

| 問題 | 回答 | 對實作的影響 |
| --- | --- | --- |
| 固定權值股清單檔數 | **前 20 大** | 依 `reference_weight_ppm` 取權重前 20；總覽精簡版顯示前 10 |

### 第 5 輪（2026-11-18）總覽細節

| 問題 | 回答 | 對實作的影響 |
| --- | --- | --- |
| 總覽版面 | **照藍圖做**（上：大盤｜台指期｜期權摘要；中：權值股｜類股；下：今日損益｜期貨權益｜持倉） | |
| 總覽走勢圖 | **加權＋台指期疊在同一張圖** | 同一價格座標，看出價差變化；夜盤只有期貨延續 |
| 期權摘要用哪個到期 | **最近到期（週選）** | 總覽以快照（約 10 秒）計算，不佔即時訂閱 |
| 類股呈現 | **熱力圖** | 方塊大小＝權重、顏色＝漲跌 |

### 第 6 輪（2026-11-18）帳務細節

| 問題 | 回答 | 對實作的影響 |
| --- | --- | --- |
| 期權整體部位分析 | 勾選**到期損益圖**、**組合 Greeks 合計**，同時也勾了「都不用」 | 解讀為：要損益圖與 Greeks，不要「指數漲跌情境表」（待使用者確認） |
| 已實現損益期間 | **可自選日期區間** | 預設本月，可選起訖日，並畫每日損益長條圖 |
| 風險指標提醒 | **低於 150% 黃、100% 紅** | 總覽與帳務頁共用門檻 |
| 庫存額外欄位 | **今日漲跌與今日損益**、**市值與佔比**（不要融資融券） | |

### 第 7 輪（2026-11-18）個股細節

| 問題 | 回答 | 對實作的影響 |
| --- | --- | --- |
| 大單標示 | 想**區分大戶與機構**，請 AI 建議 | 逐筆成交匿名、法人資料盤後才有 → 依單筆金額三級：中實戶 ≥100 萬、大戶 ≥500 萬、法人級 ≥2,000 萬；並累計各級「外盤 − 內盤」淨買 |
| 自選分組 | **可自訂多個群組** | 新增／改名／刪除群組、拖曳排序；庫存自動置頂 |
| 自選儲存 | **電腦手機同步** | 存在 phone-server（`mywatch-store.json`）；電腦也改用 `http://localhost:5180`（本機免密碼） |
| 盤中零股 | **不需要** | |

### 第 8 輪（2026-11-19）細節修改：商品頁

- 總覽熱力圖：盤後以收盤值表示；改成高刷新動畫表現資金流動（已完成）。
- **現有個股頁保留**，之後會重做；其規格可拆開放進新設計。
- 新增**商品頁**，左右並排兩張卡片：
  - 左：**商品報價小卡（個股＋期貨一起）**。固定頁籤「庫存報價」「近月＆次月期貨」（只要**微台** TMF）；其餘為自訂頁籤（與自選群組共用）。
  - 小卡內容：名稱、現價、漲跌幅、**成交量與量比**、**最佳買賣價**。
  - 右：**選擇權 T 字報價**，用小卡選擇結算日。
- 點小卡 → 將來的「**技術分析窗口**」（尚未設計）。暫時：個股 → 個股頁 K 線模式；期貨／選擇權 → 期權頁。統一由 `core/nav.ts` 的 `openTA()` 處理。

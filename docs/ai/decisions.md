# 設計決策

| 日期 | 決策 | 理由 |
| --- | --- | --- |
| 2026-11-17 | 採用 shioaji server「自訂應用」架構（HTTP + SSE），前端純網頁 | 官方推薦；金鑰只在 server `.env`，前端不碰金鑰 |
| 2026-11-17 | 不用前端框架，Vite + TypeScript + lightweight-charts | 輕量、單檔打包容易 |
| 2026-11-17 | 單一 SSE 連線 `/api/v1/stream/data` 收所有事件 | 官方建議；避免瀏覽器每網域 6 條連線上限 |
| 2026-11-17 | 台灣慣例：紅漲綠跌；深色主題 | 使用者習慣 |
| 2026-11-17 | IV/Delta 用 Black-76，標的為合成期貨 `K + C − P`，利率 0 | 夜盤不受過時現貨影響、Call/Put 一致 |
| 2026-11-17 | IV 計價優先用五檔中價（價差合理時），否則最近成交 | 減少久未成交合約的失真 |
| 2026-11-17 | 壓力／支撐以「今日成交量」最大履約價代替 | API 無選擇權未平倉量（OI） |
| 2026-11-17 | 打包成單一 `index.html` | 見 pitfalls #3 |
| 2026-11-18 | 部署用 `curl` 呼叫上傳 API，不依賴 shioaji CLI | 見 pitfalls #4 |
| 2026-11-18 | 遇 server 500/NotReady 自動重試，不中止 | server 啟動初期常見暫時錯誤 |
| 2026-11-18 | 手機透過唯讀轉接站 + 密碼 + Tailscale | shioaji server 只接受本機；封鎖下單／帳務 |
| 2026-11-18 | 期貨近月自行挑選並每分鐘檢查換月 | 見 pitfalls #1 |
| 2026-11-18 | 架構重整：core（hub 行情中心）＋ pages（四頁）＋ hash 路由 | 四大頁面共用連線與報價；訂閱引用計數避免超過上限 |
| 2026-11-18 | 未實作頁面先顯示「設計藍圖」 | 讓使用者在實作前確認版面與內容 |
| 2026-11-18 | 上方全域報價列常駐加權指數與台指期近月 | 任何頁面都能看到大盤 |
| 2026-11-18 | 權值股前 20：官方權重排行只到前 10 → 另訂閱貢獻點數正/負前 25，收集權重存 localStorage | 官方 API 限制（weight 只支援 desc/10） |
| 2026-11-18 | 總覽期權摘要用快照（10 秒）而非即時訂閱 | 省訂閱額度；快照帶最佳買賣價可算中價 |
| 2026-11-18 | 期權部位損益用永豐回傳值（15 秒），證券庫存用即時 tick 計算 | 期權部位代碼格式（TXO20261228000C）與行情代碼不同，待帳務頁處理對應 |
| 2026-11-18 | 期權部位以代碼對應實際合約（root＋年月＋履約價＋C/P），每點價值 TXF 200／MXF 50／TMF 10／臺指選 50 | 讓期權損益也即時跳動、可算 Greeks 與到期損益圖 |
| 2026-11-18 | 組合 Delta 以「約當大台口數」表示；Theta 為每天元；Vega 為 IV 每 1% 元 | 交易者直觀的單位 |
| 2026-11-18 | 到期損益圖用 SVG 自繪（橫軸為指數價格，lightweight-charts 只支援時間軸） | |
| 2026-11-18 | 風險指標門檻：低於 150% 黃、100% 紅（總覽與帳務共用） | 使用者選擇 |
| 2026-11-18 | 大單依「單筆成交金額」三級：中實戶 ≥100 萬、大戶 ≥500 萬、法人級 ≥2,000 萬，統計各級外盤−內盤淨買 | 逐筆匿名無法辨識身分；金額比張數公平（高低價股一致）；門檻存在 store.bigTiers 可調 |
| 2026-11-18 | 自選清單同步存在 phone-server 的 mywatch-store.json；電腦改用 localhost:5180 開啟 | shioaji server 的 /apps 沒有寫入端點；不需另架資料庫 |
| 2026-11-18 | K 線以 1 分 K 自行彙整成日／週／月 K（日 K 抓 200 天、週月 K 抓 400 天） | shioaji kbars 只提供 1 分 K |
| 2026-11-19 | 類股熱力圖改用 Canvas 60fps 動畫（src/ui/heatmap.ts）：緩動過渡、資金流粒子、急變光暈 | 使用者要「高品質高刷動畫表現資金流動」 |
| 2026-11-19 | 粒子密度＝類股每秒新增成交金額（group_metric amount 差分）；方向＝貢獻點數變化速度（紅往上推升、綠往下拖累） | 讓「資金流向」可視化；盤後粒子停止 |
| 2026-11-19 | 盤後熱力圖顯示最後存下的收盤值（localStorage `mw.sectorsClose`） | 見 pitfalls #7c |
| 2026-11-19 | 新增商品頁（左：報價小卡＋頁籤；右：精簡 T 字報價 ui/tchain.ts），頁籤順序 總覽｜商品｜個股｜期權｜帳務 | 使用者第 8 輪需求 |
| 2026-11-19 | 自訂頁籤＝自選群組（store.groups），與個股頁共用並電腦手機同步 | 避免兩套清單 |
| 2026-11-19 | 只訂閱目前頁籤的小卡（Tick＋BidAsk）；T 字報價 ±8 檔 | 控制 shioaji 訂閱上限（約 200） |
| 2026-11-19 | 點商品統一走 core/nav.ts openTA() | 技術分析窗口完成後只改一處 |
| 2026-11-26 | 個股盤中分時圖：時間軸固定 09:00–13:30、價格軸以參考價為中心上下對稱（最小 ±0.5%）、高度隨視窗（360–760px） | 使用者要求以開收盤為錨點、大小適中；符合一般看盤軟體習慣 |
| 2026-11-26 | 總覽版面：左側 6 卡等寬等高（大盤｜台指期｜期權摘要／今日損益｜期貨權益｜持倉），右側走勢圖等高；下方權值股｜熱力圖 | 使用者要求卡片縮小、帳務移到大盤下方、走勢圖縮小放右側 |
| 2026-11-26 | 總覽走勢圖「日盤／全時」切換；全時＝券商全盤日K起迄（前一交易日 15:00 → 當日 13:45）；預設依時段自動切換，手動切換後本次停留以手動為準 | 使用者確認 |
| 2026-11-26 | 個股盤中「大單統計」加散戶（<100 萬）列，下方加四條累計淨買線（散戶／中實戶／大戶／法人級，外盤−內盤金額，橫軸 09:00–13:30） | 使用者：累計圖對操盤非常有幫助 |
| 2026-11-26 | 大單改**混合分級**：金額與張數都達標才算該級——散戶 <100萬或≤2張、中實戶 ≥100萬且≥3張、大戶 ≥500萬且≥10張、法人級 ≥2,000萬且≥50張（store.bigTiers／bigLots） | 純金額分級時高價股（台積電 1 張就 >100 萬）沒有散戶；使用者選混合方式 |
| 2026-11-26 | 個股盤中三欄高度＝ `100vh − 208px`（≥1401px），使用者 1920×1080 螢幕的瀏覽器可視高度約 912px 不需捲動 | 使用者要求現行解析度不出現捲軸 |
| 2026-11-26 | 「今日損益」＝今日已實現＋持倉今日變動；證券昨日已持有部分以昨收計、今天新買部分（quantity − yd_quantity）以成本計；期權以參考價計。累計未實現另列「參考」，不算進今日（account.stockDayPnl／futDayPnl） | 使用者回報今日損益數字怪：舊版把累計未實現整筆算進今日 |
| 2026-11-27 | 帳務頁沒有期權部位時收合 Greeks／部位／到期損益圖（`.acct.ac-nofut`） | 1920×912 畫面大半空白 |
